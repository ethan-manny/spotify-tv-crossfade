# Spotify TV Crossfade (Morphe patches)

Adds crossfade between songs to the Spotify TV app (`com.spotify.tv.android` 1.134.2, Fire TV) by
placing a native audio library between Spotify's embedded player (the eSDK) and the system OpenSL
ES. The patched app loads `libxfade.so`, which presents the OpenSL ES surface the eSDK expects,
buffers the PCM stream and mixes the end of one track into the start of the next before handing it
to the real OpenSL ES underneath.

A track that plays to its end fades into the next one over 0 to 12 seconds. A manual skip, a
previous, a track picked from a list and a seek inside a track all switch instantly.

The bundle is made of three deliverables:

- `native/`: the C++ library `libxfade.so` (fake OpenSL ES front end, ring pipeline, boundary
  model, equal-power mixer, real back end, JNI) and its on-device tests.
- `extensions/extension/`: the Java extension the patched app runs: loads the library, parses the
  eSDK's metadata, detects the long press and hosts the settings screen.
- `patches/`: the Morphe patches (Kotlin) that inject the library, repoint the eSDK's OpenSL ES
  dependency at it, hook `SpotifyTVApplication.onCreate`, the metadata callback and
  `dispatchKeyEvent`, and disable the Amazon Appstore DRM checks.

## 🎚️ Setting the crossfade length

Long-press the remote's Menu button to open the on-screen setting; Left/Right adjust it 0 to 12
seconds, Back closes it. It can also be set without the UI over adb:

```
adb shell am start -n com.spotify.tv.android/dev.spotifytv.crossfade.extension.CrossfadeSettingsActivity --ei crossfade_seconds 6
```

## ⚠️ Known limitations

Video content bypasses the eSDK, so it cannot be crossfaded; digital silence just after a track
boundary is dropped; the progress bar runs ahead of the audio; the patch is 32-bit ARM only and
pinned to app version 1.134.2. The full list is in
[docs/overview.md](docs/overview.md#known-limitations).

## 🛠️ Building locally

- Run `./gradlew buildAndroid`
- The built patches .mpp file is found in `patches/build/libs/patches-*.mpp`
- Patch the mpp file using [Morphe-Desktop](https://github.com/MorpheApp/morphe-desktop)
  like any other patch bundle (`scripts/patch-and-install.sh` does this, verifies the result
  and installs it).

Full instructions, including the native build and the device scripts, are in
[docs/building.md](docs/building.md). See the
[Morphe documentation](https://github.com/MorpheApp/morphe-documentation) for more information.
